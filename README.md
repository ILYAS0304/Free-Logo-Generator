# Logo Crafter

A lightweight logo prototyping tool that runs entirely in the browser. Provide a brand name, optional tagline, and pick from curated palettes and shapes to generate a crisp PNG logo that is perfect for presentations, mockups, or inspiration.

## Features

- 🎨 Multiple curated color palettes and geometric bases
- 🌀 Canvas rendered shapes with dynamic shadows
- 🔤 Randomized typography pairings for unique results
- 📥 One-click PNG export
- 📱 Responsive design suitable for desktop and mobile

## Getting started

1. Open `index.html` in your browser.
2. Enter your brand name, choose a shape and palette, and press **Generate logo**.
3. Download the generated PNG or iterate with new combinations.

## Project structure

```
├── index.html      # UI layout and form
├── main.js         # Canvas drawing logic
└── styles.css      # Styling for the interface
```

No build step is required; everything runs with vanilla HTML, CSS, and JavaScript.
